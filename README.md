# easy-yt-dlp

A simple GUI wrapper for **yt-dlp**

made for people who find the command line annoying!

## Features

- Simple GUI (no command line needed)
- Download video / audio based on ur choose
- Automaticvally downloads `yt-dlp` from [Latest yt-dlp releases](https://github.com/yt-dlp/yt-dlp/releases)

## Usage

1. download the latest `.exe` from the [Releases page](https://github.com/ronaldooo0/easy-yt-dlp/releases).

2. run the executable

### Notes

- this tool uses **yt-dlp** internally
- Please make sure you comply with the terms of service of the website you are downloading from.

---

> Currently tested **only on Windows**
